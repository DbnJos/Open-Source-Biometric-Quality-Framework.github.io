# Contributor's Guide

OpenBQ is an open-source biometric quality framework developed and maintained by Biometix Pty Ltd. We welcome contributions from developers, testers, researchers and documentation writers.

## Where to start?

- Read the [Getting Started](../getting_started/) guide to install and run OpenBQ.
- Browse the repositories in the [OpenBQ GitHub organisation](https://github.com/Open-Source-Biometric-Quality-Framework).
- Create a [GitHub account](https://github.com/signup) if you don't have one.
- Read our [Code of Conduct](code-of-conduct/).

## Areas of contribution

**Code**
- Fix bugs and implement new features
- Add or improve quality metrics and modality support
- Improve performance and integrations

**Testing**
- Test OpenBQ on different datasets, platforms and environments
- Report bugs with clear steps to reproduce

**Documentation**
- Improve guides, tutorials and the cookbook
- Fix errors and fill gaps in these docs

**Research and design**
- Share feedback on quality measures and standards alignment
- Propose enhancements through GitHub Issues

## Ready to fix an issue?

Follow the [GitHub Workflow](github-workflow/) to fork, branch, sign off your commits and raise a pull request.

## Found an issue or have an enhancement request?

Open an issue in the relevant repository, following the [Issue Reporting Guidelines](issue-reporting/).
