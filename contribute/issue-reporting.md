# Issue Reporting Guidelines

Report bugs and enhancement requests as GitHub Issues in the relevant repository in the [OpenBQ GitHub organisation](https://github.com/Open-Source-Biometric-Quality-Framework).

## Before you report

- Search existing issues to check it hasn't already been reported.
- Make sure you are using the latest version.

## What to include

- **Title:** a short, clear summary of the problem
- **Repository and version** you are using
- **Environment:** operating system, Python version, Docker or local install
- **Steps to reproduce:** numbered steps someone else can follow
- **Expected behaviour** and **actual behaviour**
- **Logs or screenshots**, where helpful (remove any personal or biometric data first)

## Enhancement requests

Describe the problem you want solved, your proposed solution, and any alternatives you considered.

## Security vulnerabilities

Do not report security vulnerabilities in public issues. Email [SECURITY CONTACT EMAIL] instead.
